## ８．ウェブラジオ  
    
初版 2026/07/14    
　版 2026/07/14   
  
以下の配信データを時間を指定(予約機能)して、リアルタイム録音、リアルタイム再生、ファイル再生します。  
・ラジコ  
・らじるらじる  
・WebRadio (ottava,afngo,listenradio,jcba)    

ここでは、主にWebRadioを例に説明します。  
ラジコ、らじるも同様です。

### 8.2 予約フォーマット   
  
予約フォーマットは、以下のとおりです。  
  
局名,曜日,開始時間,終了時間,タイトル,アーティスト  
または  
局名,曜日,開始時間,終了時間,タイトル,アーティスト,タイプ  
  
例  
OTTAVA,SUN,10:00,12:00,ottava番組,ottavaアーティスト  

  
#### 8.2.1 局名  
  
以下のような簡単なルールで判定しています。   
  
・OTTAVA  
  
  OTTAVAの局名はこれのみ  
  
・AFNX-XXX  
  
  詳細な局名は、webradioのAFNGOの聴取画面で確認してください。  
  
  AFNP-TKO (Pacific)など  
  AFNE-AVN (Europe)など  
  
・XXXXX ListenRadio-id  
  
  数字5桁です。  
  詳細な局名は、webradioのListenRadioの聴取画面で確認してください。  

  ・XXXXX jcba-id  
  
  英字です。  
  詳細な局名は、webradioのjcbaの聴取画面で確認してください。  
  
  <img width="416" height="287" alt="clip_5" src="https://github.com/user-attachments/assets/7b61c6bb-31dc-4ac4-b11b-a52d978c8fc1" />  
  
#### 8.2.2 曜日  
  
SUN,MON,...,SATです。   
  
なお、TODAYと指定すると、本日という意味になります。  
予約を選択した日を意味し、現在時刻が終了時間を過ぎている場合は予約しません。  
  
#### 8.2.3 開始時間  
  
時:分で指定してください。     
  
#### 8.2.4 終了時間  
  
時:分で指定してください。   
または、単に分のみを指定すると、開始時間＋分が終了時間になります。  
  
#### 8.2.5 タイトル  

タイプにより意味が異なります。  
REC : 録音するファイルのタイトルです。  
PLAY : 予約名のタイトルです。  
FILE : 再生するファイルのタイトルです。  
  
#### 8.2.6 アーティスト  
  
録音するファイルのアーティストタグです。    
  
#### 8.2.7 タイプ  
  
REC または無指定 : 録音  
PLAY : 配信データをリアルタイム再生  
FILE : 録音データを再生 (1.6.1以降)  

FILEタイプの仕組み(ここだけ、radikoの例)  
```    
radikoディレクトリ  
LFR_伊集院光のタネ_20260604_1730_1750.m4a  
LFR_伊集院光のタネ_20260603_1730_1750.m4a  
...  
  
:radiko_timerec  
LFR,SUN,11:00,11:10,伊集院光のタネ,伊集院光,file
```  
LFR_伊集院光のタネをキーワードにradikoディレクトリ内の最新のものを再生。   
ファイルが20分あっても、指定が10分の場合は、10分で再生は終了します。  
  
なお、radikoの場合、radikoディレクトリ内に該当ファイルが存在しない場合、timefreeディレクトリ内を探します。  
radiruの場合、radiruディレクトリ内に該当ファイルが存在しない場合、radiru_vod,radiru_gogakuディレクトリ内を探します。
  
キーワードは、完全一致が原則ですが、伊集院光の*
のように、最後に*をつけて省略可能。

### 8.4 自動予約   
  
従来からある定期実行機能で、自動予約が可能です。  
  
設定 - パラメータ - 編集  (247行あたり)  
webradioを"on"にしてください。  
定期実行設定の時間に自動予約が実行されます。  
  
```  
sch_rsv_radiko = "on"
sch_rsv_radiru = "on"
sch_rsv_timefree = "on"
sch_rsv_radiru_vod = "on"
sch_rsv_radiru_gogaku = "on"
sch_rsv_podcast = "on"
sch_rsv_webradio = "on"
```    
  
### 8.5 その他   
  
OTTAVA,AFNGOのデータフォーマットは、mp3 です。  
Listen Radioのデータフォーマットは、m4a です。  
JCBAのデータフォーマットはogg(opus)ですが、m4aに変換しています。

JCBA 以外は配信されているデジタルデータをそのまま保存しています。  
局により、音質のばらつきがあります。  
  
番組表からの番組予約は局数が多く煩雑なため、対応の予定はありません。  
どうして、radiko,radiru,webradioだけなのという質問をいただきますが、  
リアルタイム配信が、その3つだけだからです。 
  
timefree,radiru_vodのファイル再生については、「8.2.7 タイプ」 で対応しています。
  
まだ、粗削りのため、バグはあると思うので、掲示板等で報告していただくと助かります。
