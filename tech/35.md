## rfriends3のdelivery機能にftp copyを追加する。  
  
初版 2026/03/18  
  
delivery機能とは、radiko/radiruの録音時に任意のディレクトリにデータをcopy/moveする機能です。  
キーワード - 番組配送で設定できます。  
  
今回はこれに、ftp serverが動作している他PCやNASへのcopy/move機能を追加しました。  

> [!NOTE]
>  ftpはたいていのNASで利用可能です。
  
### １．クライアント側  
  
rfriends3を実行しているPCでの設定です。  
ftp機能は標準なので、追加処置は不要です。  
  
### ２．サーバ側  
  
録音データをコピーするPC,NAS側の設定です。  
  
ftp server機能があっても、停止している場合があるので、起動してください。  
  
### ３．delivery機能の設定  
  
キーワード - 番組配送、を開き設定を行います。  
従来の自PCの場合は、以下のようになります。  
  
例：「深夜の馬鹿力」を/home/rpi/smbdir/user1/radiko/にコピーする。  
  
~~~  
:dlvy  
on  
#  
:dlvy_users  
user1  
#  
:dlvy_user1_radiko_dir  
/home/rpi/smbdir/user1/radiko/  
#  
:dlvy_user1_radiko_copy  
TBS,JUNK,深夜の馬鹿力  
~~~  
  
これに、user2を追加し、ftp serverにコピーします。  
例：「オールナイトニッポン」を192.168.1.100の/home/hoge/radiko/にコピーする。  
  
ftpサーバ:192.168.1.100  
ユーザ: hoge  
パスワード:pass  
  
~~~  
:dlvy_users  
user1  
user2  
#  
:dlvy_user2_radiko_dir  
/home/hoge/radiko  
ftp  
192.168.1.100  
hoge,pass  
#  
:dlvy_user2_radiko_copy  
LFR,オールナイトニッポン  
~~~  
  
通常の設定と違う点は以下の個所のみです。  
  
ftp  
192.168.1.100  
hoge,pass
