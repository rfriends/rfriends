## (easy インストール) Debian 版rfriends3でラジオ録音    
    
Debian 版rfriends3 を簡単にインストールする方法です。  
    
初 版　2026/08/19     
    
## １．前提    
    
Debian系LinuxがインストールされたPCを対象としています。  
    
・Debian  
・Raspbian  
・DiePi  
・Kali linux  
・Chromeos  
・Android(pixel)  
・Devuan  
・MX linux  
・antiX linux  
  
など    
  
GUI環境が必要です。  
CUI環境の方はこちら -> [Debian版rfriends3でラジオ録音](../distro/rfriends3_debian.md)  
    
    
~~## ２．実行SHのダウンロード~~  
  

    
## ３．rfriends3のインストール  
  
Terminalを開き、以下を入力する。    
    
```  
curl -LO rfriends.github.io/debian.sh
sh debian.sh    
```     
  
インストール完了まで、しばらくお待ちください。    
  
**インストールが完了したら、PCを再起動してください。**  
    
## ４．rfriends3の実行    
    
ウェブブラウザ（edge,chrome,firefox,...）を起動し、以下を入力します。  
  
```  
localhost:8000  
```
