## (easy インストール) Debian 版rfriends3でラジオ録音    
    
Debian 版rfriends3 を簡単にインストールする方法です。  
    
初 版　2026/08/19     
    
## １．前提    
    
Debian系LinuxがインストールされたPCを対象としています。  
    
・Debian  
・Raspbian  
・DiePi  
・Kali linux  
・Chromeos  
・Android(pixel)  
・Devuan  
・MX linux  
・antiX linux  
  
など  
    
## ２．実行SHのダウンロード  
  
以下のリンクを右クリックし、ホームディレクトリに保存してください。  
  
[rf3debian.sh](https://ss1.xrea.com/rf3.s331.xrea.com/rf3debian.sh)  
    
## ３．rfriends3のインストール  
  
Terminalを開き、以下を入力し、rf3debian.shを実行する。    
    
```  
$ cd    
$ sh rf3debian.sh    
```     
  
インストール完了まで、しばらくお待ちください。    
  
**インストールが完了したら、PCを再起動してください。**  
    
## ４．rfriends3の実行    
    
ウェブブラウザ（edge,chrome,firefox,...）を起動し、以下を入力します。  
  
```  
localhost:8000  
```    
    
以下のような画面が出たら成功です。
