## JCBAの聴取で音を出す方法(Lighttpd) 
    
初版 2026/07/08  
二版 2026/07/08   
  
  
ＷＥＢサーバがLighttpdの場合、JCBAの聴取で音が出ません。  
以下のことを行ってください。    
  
### １．Linuxの場合    
  
SSH等でサーバのターミナルにアクセスし、rfriends3のインストールディレクトリに移動します。  
ここではホームディレクトリを想定しています。  
rfriends3のインストール場所が違う場合は、読み替えてください。  
  
```
cd ~/
cd rfriends3
sudo set_lighttpd.sh    
```  

### ２．その他の場合    
  
設定ファイルlighttpd.confを編集し、以下を追加してください。  
  
```  
server.stream-response-body = 1    
```  

保存したら、
ＷＥＢサーバ(Lighttpd)を再起動してください。
