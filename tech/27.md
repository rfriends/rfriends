## webradioを録音する。  
    
初版 2026/06/20    
五版 2026/07/09   
  
  
現在、rfriends3には、webradioメニューとして、ottava,afngo,listenradio,jcbaの４つがあり、  
聴取。聴取（サーバ）機能を持っています。  
今回、それに予約録音機能を追加しました。

### ３．予約フォーマット   
  
#### 3.1 フォーマット  
  
radiko,radiruのtimerecと同一です。  
  
局名,曜日,開始時間,終了時間,タイトル,アーティスト  
  
例  
OTTAVA,SUN,10:00,12:00,ottava番組,ottavaアーティスト  

アーティストの後に
,play
をつけると録音の代わりに再生します。(1.5.0c以降)  
  
#### 3.2 局名  
  
以下のような簡単なルールで判定しています。   
  
・OTTAVA  
  
  OTTAVAの局名はこれのみ  
  
・AFNX-XXX  
  
  詳細な局名は、webradioのAFNGOの聴取画面で確認してください。  
  
  AFNP-TKO (Pacific)など  
  AFNE-AVN (Europe)など  
  
・XXXXX ListenRadio-id  
  
  数字5桁です。  
  詳細な局名は、webradioのListenRadioの聴取画面で確認してください。  

  ・XXXXX jcba-id  
  
  英字です。  
  詳細な局名は、webradioのjcbaの聴取画面で確認してください。

### ４．自動予約   
  
従来からある定期実行機能で、自動予約が可能です。  
  
設定 - パラメータ - 編集  (247行あたり)  
webradioを"on"にしてください。  
定期実行設定の時間に自動予約が実行されます。  
  
```  
sch_rsv_radiko = "on"
sch_rsv_radiru = "on"
sch_rsv_timefree = "on"
sch_rsv_radiru_vod = "on"
sch_rsv_radiru_gogaku = "on"
sch_rsv_podcast = "on"
sch_rsv_webradio = "on"
```    
  
### ５．その他   
  
OTTAVA,AFNGOのデータフォーマットは、mp3 です。  
Listen Radioのデータフォーマットは、m4a です。  
JCBAのデータフォーマットはogg(opus)ですが、m4aに変換しています。

JCBA 以外は配信されているデジタルデータをそのまま保存しています。  
局により、音質のばらつきがあります。  
  
番組表からの番組予約は局数が多く煩雑なため、対応の予定はありません。  
  
まだ、粗削りのため、バグはあると思うので、掲示板等で報告していただくと助かります。
