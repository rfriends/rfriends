## １．AIチャプターとは  
  
AIがラジオ番組の内容を解析し、聴きたい場面からすぐに再生できるようにする機能です。  
この機能により、ユーザーは番組の内容を聴く前に把握でき、興味に合わせて気軽に聴き始めることができます。  
  
## ２．AIチャプターの仕組み  
  
radikoのtimefreeは、2026/09/19現在、  
  
・放送後、約5分で、ファイルがダウンロードできるようになります。  
・放送後、約60分から80分で、チャプターファイルがダウンロードできるようになります。  
　ただし、チャプターに対応していない番組もあります。  
  (まれに30分程度でチャプターがダウンロードできることもあります。)
  
  
注意すべき点は、放送後5分から80分までの間はチャプターなしの状態が続くということです。

## ４．timefreeの設定  
  
以下、version 1.6.3aで説明します。  
1.6.3 -> 1.6.3aで一部仕様変更があります。  
  
設定 - パラメータ - 編集　535行あたりで変更できます。  
  
```  
;; チャプター  
;; timefree_chapter 0:なし,1:あり,2:あり(time付)  
;; timefree_chapter_ai 0:なし,1:あり  
;; timefree_chapter_music 0:なし,1:あり  
```  
  
### 4.1 従来モード  
  
timefree_chapter = 0  
  
従来モードで、チャプターのないファイルがダウンロードされます。  
ファイル.m4aで、後述の、_nochapterは付加されません。  
  
### 4.2 チャプターモード  
  
timefree_chapter = 1 又は 2  
  
チャプター付きのファイルがダウンロードされます。  
1と2の違いは、２のばあい、チャプターの先頭に時間が表示されます。

## ５．podcastの設定  
  
現在、未実装

この機能はradiko podcast のみ
同じ番組でも、radiko以外では機能しません。
  
設定 - パラメータ - 編集　660行あたりで変更できます。  
  
```  
;; チャプター  
;; podcast_chapter  
;;  0:なし  
;;  1:あり,2:あり(time付) 2026/09/23現在、無効  
;;  3:cue,4:cue(time付)   2026/09/23現在、無効   
;; 
podcast_chapter = 4
```  
  
### 5.1 従来モード  
  
podcast_chapter = 0  
  
従来モードで、チャプター/cueシートのないファイルがダウンロードされます。  
ファイル.mp3で、_nochapterは付加されません。  
  
### 5.2 チャプターモード   
  
podcast_chapter = 1 又は 2  
  
チャプター付きのファイルがダウンロードされます。  
1と2の違いは、２のばあい、チャプターの先頭に時間が表示されます。  
    
### 5.3 cueシートモード  
  
podcast_chapter = 3 又は 4  
  
チャプター情報がある場合、ファイル名.cue として、podcastファイルとは別のファイルがダウンロードされます。   
再生には、cueシートに対応したプレーヤが必要になります。  
  
3と4の違いは、4のばあい、チャプターの先頭に時間が表示されます。  
  
## ６ チャプターモード時のダウンロードの仕組みについて  
  
２．でも述べたように、放送後5分から80分までの間はチャプターなしの状態が続くため、その間にタイムフリーでダウンロードするとチャプター情報が得られません。  
  
そこで、rfriends3では、チャプターモードの場合、以下のような対応を行っています。  
  
1) チャプター情報がない場合は、ダウンロードしたファイルを  
ファイル_nochapter.m4a と、_nochapterを付加して保存します。  
  
2) その後（例えば放送2時間後）、再度ダウンロードを行うと  
チャプター付きの ファイル.m4a がダウンロードされ、ファイル_nochapter.m4a は削除されます。
 
## ７．その他
