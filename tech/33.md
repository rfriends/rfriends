## (easy インストール) Ubuntu 版rfriends3でラジオ録音   
    
ubuntu版rfriends3 を簡単にインストールする方法です。  

    
初 版　2026/08/19     
    
## １．前提    
    
ubuntu系LinuxがインストールされたPCを対象としています。  
    
・Ubuntu / Lubuntu
・Linux Mint  
・ZORIN OS
  
など  
  
GUI環境が必要です。  
CUI環境の方はこちら -> [Ubuntu版rfriends3でラジオ録音](../distro/rfriends3_ubuntu.md)  
    
~~## ２．実行SHのダウンロード~~  
  
    
## ３．rfriends3のインストール  
  
Terminalを開き、以下を入力する。    
    
```  
curl -LO rfriends.github.io/ubuntu.sh
sh ubuntu.sh    
```     
  
インストール完了まで、しばらくお待ちください。    
  
**インストールが完了したら、PCを再起動してください。**  
    
## ４．rfriends3の実行    
    
ウェブブラウザ（edge,chrome,firefox,...）を起動し、以下を入力します。  
  
```  
localhost:8000  
```
